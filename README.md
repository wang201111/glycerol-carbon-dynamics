# Glycerol Carbon Dynamics: Joint Prediction of Glycerol Oxidation Performance

Implementation of **A conditional neural dynamics model constrained by a shared carbon transfer structure for joint prediction of glycerol oxidation performance**.

## Overview

Glycerol oxidation experiments report different subsets of products under different catalysts and operating conditions. The model uses these partial observations to learn a common catalyst- and condition-dependent representation of carbon transfer.

1. **Shared carbon-transfer structure.** Seven carbon states and 31 candidate connections organize glycerol consumption, target-product interconversion and other carbon destinations. A shared neural network maps catalyst descriptors and operating conditions to effective transfer parameters.
2. **Hierarchical carbon allocation.** The allocation separates the share entering the target-product set from its distribution among individual products.
3. **Joint state evolution.** Nonnegative, carbon-conserving evolution generates conversion, target C₃ carbon yield, selectivity and individual product yields. Only available experimental observations enter supervision.

The dataset contains 506 records from 23 publications and 112 catalyst instances. In the paper's five fixed test splits, the final model gives the following results after averaging predictions from initializations 5 and 11 within each split.

| Quantity | Test R², mean ± SD |
|---|---|
| Glycerol conversion | 0.913 ± 0.030 |
| Target C₃ carbon yield | 0.884 ± 0.043 |
| Target C₃ selectivity | 0.896 ± 0.051 |

## Quick Start

```python
from src.models.carbon_dynamics import CarbonDynamicsConfig, CarbonDynamics
from src.models.utils_glycerol import StudyDataset

# Load a frozen split and configure the model.
data = StudyDataset.load(split=101)
config = CarbonDynamicsConfig()
model = CarbonDynamics(split=101, seed=5, config=config, device="auto")

# Train, predict, save and load.
model.fit(data)
prediction = model.predict(data.frame.head())
model.save("results/model.pt")
restored = CarbonDynamics.load("results/model.pt", device="auto")
prediction = restored.predict(data.frame.head())
```

`predict` accepts the input columns used in `data/glycerol.csv` and ignores response columns. It returns conversion, C₃ yield, selectivity and individual product yields on the 0–100 scale, together with carbon-state fractions. `trajectory(profile, time_min)` generates time-dependent predictions for one catalyst and non-time condition profile.

## Reproducing the Experiments

Run the main experiment from the project root.

```bash
python experiments/glycerol_experiment.py
```

The script uses frozen splits **101, 123, 314, 73 and 202**, with initialization seeds **5 and 11**. Each fit selects its checkpoint using validation loss. Predictions are averaged across the two initializations before scoring; the final summary uses the unweighted mean and sample standard deviation across splits. Saved models, predictions, split metrics and the summary are written to `results/main/`.

For a single fit, use `--split 101 --seed 5`. Add `--smoke-test` for a three-update execution check. Model hyperparameters are centralized in `CarbonDynamicsConfig`. Use a new output directory for each run.

Prediction from the two saved initialization models uses the same experiment entry point.

```bash
python experiments/glycerol_experiment.py --mode predict --checkpoint results/main/s101_i5.pt results/main/s101_i11.pt --input data/glycerol.csv --output-dir results/prediction
```

Model files are generated by training and contain the fitted preprocessing, resolved configuration, weights and training history. Pretrained weights are not distributed in this release.

## Data

| File | Description |
|---|---|
| `data/glycerol.csv` | Catalyst information, reaction conditions and observed responses |
| `data/fixed_splits.npz` | Frozen features, labels, row identifiers and train/validation/test positions |
| `data/preprocessing.json` | Saved numeric/categorical encoders, missing-value handling and time contexts |
| `data/literature_sources.csv` | Source identifiers, DOIs and included-record counts |

The target products are glyceraldehyde (GLYD), dihydroxyacetone (DHA), glyceric acid (GLYA), tartronic acid (TART) and lactic acid (LA). Time is recorded in minutes, temperature in kelvin and pressure in bar. Material descriptors include metal loading, particle size, BET surface area, pore volume and XPS binding energy. Missing product observations remain missing.

The five source-covered row-level partitions and fitted preprocessing are supplied for direct reuse. Base preprocessing retains the original training-input statistics; additional encoders use supervised training rows. Data sources are identified by `paper_id` and the DOI map. Cite the original publications when reusing their observations.
